# Growth Experiment Template

A lightweight framework for running product and marketing experiments.

The goal is to make hypotheses explicit, ship quickly, and capture learnings so experimentation becomes repeatable.

---

## Experiment Structure

### 1. Hypothesis

What do we believe will happen and why?

Example:

> Simplifying the paywall will increase trial starts by reducing cognitive load.

---

### 2. Implementation

What changed?

* UI variants
* Copy changes
* Feature flags
* Audience targeting
* Experiment duration

---

### 3. Metrics

Primary metric:

* Conversion / activation / revenue

Supporting metrics:

* Drop-off points
* Engagement
* Qualitative feedback

---

### 4. Decision

* Ship
* Iterate
* Kill

Include reasoning.

---

### 5. Learnings

Document behavioural insights even if the test fails.

---

## Why this exists

Most teams run experiments but don’t capture thinking.
This template turns growth work into a system.
